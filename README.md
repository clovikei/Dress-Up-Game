## Description
A simple character dress-up game made with Python and Pygame.

Features the cute duck character "Oguri" and 5 outfits to choose from or mismatch to create hundreds of unique combinations. Files in assets folder contain character and character clothing assets as well as music and sfx. On the right side of the screen is a wardrobe with hat, top, and bottom options. Thumbnails are included and visually switch depending on what is selected and appears on the character. Button clicks trigger sfx. A bouncy BGM plays in the background and loops. The visual look is very simple and cute with a pink color scheme. Each outfit is a unique style. 

It has 4 functions: importing assets, outfit randomizer, thumbnails, and wardrobe.

In the future, some areas of improvement could be adding a title screen, character outfit save function, custom background, and more outfit options. In general, just adding more customizable aspects.
